雲端聯絡簿 操作說明

五年二班雲端聯絡簿,讓施老師登打每日回家作業與聯絡事項,家長、學生、班長可以隨時上線查看。手機、電腦瀏覽器皆可開啟使用,不需要另外安裝 App。

一、登入方式

開啟頁面後,請先選擇身份:

身份	是否需要密碼	說明
施老師	需要,密碼 705115	可登打、發布每日聯絡簿內容
班長	需要,密碼 705115	可查看聯絡簿內容,並看到全班已讀進度
家長 / 學生	不需要密碼	點選後可直接進入,查看聯絡簿內容
二、施老師 — 登打聯絡事項
登入後畫面上方就是登打表單。
選擇日期(預設為今天)。
在「回家作業」區塊,點「＋ 新增一項作業」可以新增多筆作業項目,每一項可自由輸入文字,也可以按旁邊的「✕」刪除。
在「聯絡事項 / 公告」欄位輸入當天要提醒家長的事(例如:校外教學繳費、天氣提醒、活動通知)。
確認內容後按「蓋章送出」,這則聯絡簿就會發布出去,家長與班長就能看到。
左側書背會列出歷史紀錄的日期,點選任一天可以切回去該天,如果需要修改,重新編輯同一個日期再按一次「蓋章送出」即可覆蓋更新。
三、班長 — 查看與追蹤已讀進度
登入後可以看到每天的聯絡簿內容(作業、聯絡事項),但無法編輯。
畫面上方會顯示「全班家長已讀進度」,方便班長掌握還有哪些家長尚未讀取聯絡簿。
左側書背一樣可以點選日期,回顧過去的紀錄。
四、家長 / 學生 — 查看聯絡簿
不需要密碼,選擇「家長 / 學生」身份後按「進入聯絡簿」即可查看。
可以看到當天及過去的回家作業、聯絡事項,以及老師的確認印章。
看完每則聯絡簿後,可以按「標記已讀」,老師與班長端就會看到已讀狀態。
左側書背可以點選不同日期,回顧之前的紀錄。
五、支援手機瀏覽
手機開啟時,畫面會自動改成適合手機的排版(側欄變成上方橫排、內容單欄顯示),不需要縮放就能操作。
所有功能都是用點擊操作,不依賴滑鼠,手機、平板、電腦都能正常使用。
六、目前為原型,尚待補強的部分

這個版本目前是前端展示原型,方便討論功能與畫面,還不是能正式上線給全班使用的系統。若要正式使用,建議接下來處理:

帳號與資料儲存:目前資料只存在瀏覽器記憶體中,重新整理頁面或換裝置就會消失,需要接上雲端資料庫才能長期保存。
每位家長獨立帳號:目前家長/學生是共用同一個入口,看不到「哪一位家長」讀了,只知道「有沒有人讀」。若要精確追蹤每位家長的已讀狀態,建議之後改為每個家庭各自一組帳號。
密碼安全性:目前的密碼是寫在網頁程式裡,任何人打開原始碼都看得到,只能防止隨便點進去,還不算是正式的登入驗證機制,正式上線前建議改為後端驗證。
通知提醒:目前家長需要自己打開網頁查看,若想讓家長更即時收到通知,可以考慮之後串接 LINE 或手機推播。
